🎮 Elden Ring Face Slider Generator

An automated web tool designed to convert face photos and facial landmark measurements into accurate Elden Ring character creation sliders.

Powered by MediaPipe landmark analysis, this application processes facial proportions, features, skin tone, and features to calculate matching target values for all primary character options in the game.

✨ Features

Complete Slider Extraction: Generates values for all 78 adjustable sliders across every character creation category in Elden Ring.

Frontal Pose Analysis: Calculates Yaw, Pitch, and Roll angles to ensure input photos meet accurate front-facing requirements.

Smart Parameter Mapping:

Facial Geometry: Dynamically maps balance, nose length, lip thickness, jaw contours, and structure to 0–255 numerical ranges.

Skin & Cosmetics: Extracts exact RGB values for skin tone, eye color, hair, and cosmetics.

Categorical Options: Handles strict discrete options for Base Age (Young, Mature, Aged), Body Muscle (Standard, Muscular), Eyebrows, Hair, Voice Types, and Facial Hair.

Name Generator: Includes an interactive name generator tailored to character gender selection.

🛠️ Technology Stack
HTML5 / CSS3 (Vanilla UI with responsive grid cards)

JavaScript (ES6+)

MediaPipe Face Landmarker (Facial measurement and pose analysis)

🚀 Quick Start

1. Clone the repository: https://github.com/krisuuhh/elden-sliders-tool.git or just go to page https://krisuuhh.github.io/Elden-Sliders-Tool/
2. Open index.html directly in any modern web browser (no complex build step required).
3. Upload a front-facing image to generate your 78 character creation sliders.
